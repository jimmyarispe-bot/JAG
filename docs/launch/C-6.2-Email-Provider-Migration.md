# C-6.2 — Email Provider Migration (SendGrid → Resend)

**Status:** Implemented in code  
**Provider:** [Resend](https://resend.com) via official `resend` SDK  
**Abstraction:** `src/lib/platform/email/`

---

## What changed

| Before | After |
|--------|-------|
| `SENDGRID_API_KEY` + raw `fetch` to api.sendgrid.com | `RESEND_API_KEY` + `resend` SDK |
| `src/lib/platform/email/sendgrid.ts` | Pluggable `EmailProvider` + Resend implementation |
| Supabase `inviteUserByEmail` SMTP for invites | Auth user + `generateLink` + Resend invitation email |

## Architecture

```
Call sites
  → sendTransactionalEmail / sendPasswordResetEmail / sendInvitationEmail / …
  → getEmailProvider()
  → ResendEmailProvider (production/preview) | NoneProvider (dev without key)
```

Files:

- `types.ts` — `EmailProvider` contract
- `provider.ts` — env-based resolution
- `providers/resend.ts` — official SDK
- `send.ts` — typed helpers (reset, invite, welcome, verification, system)
- `index.ts` — public barrel

## Migrated email kinds

| Kind | Entry point | Used by |
|------|-------------|---------|
| Password reset | `sendPasswordResetEmail` | Users & Access → Reset Password |
| Invitation | `sendInvitationEmail` | Create/Invite user (`pending_invite`) |
| Welcome | `sendWelcomeEmail` | Active user create |
| Verification | `sendVerificationEmail` | Available for auth verification flows |
| System / admissions | `sendTransactionalEmail` / `sendSystemNotificationEmail` | Admissions communications, automation `send_email` |

## Environment

Required (preview + production):

- `RESEND_API_KEY`
- Recommended: `EMAIL_FROM=noreply@theacademyway.org` (verify `theacademyway.org` in Resend), `RESEND_FROM_NAME=The Academy Way`
- Legacy alias: `RESEND_FROM_EMAIL` (used only when `EMAIL_FROM` is unset)

Remove from Vercel (obsolete):

- `SENDGRID_API_KEY`
- `SENDGRID_FROM_EMAIL`
- `SENDGRID_FROM_NAME`

Canonical: `.env.example`, `docs/launch/PRODUCTION_ENV.md`, `src/lib/platform/env/schema.ts`.

## Preview / Production verification

1. Set `RESEND_API_KEY` + verified `EMAIL_FROM=noreply@theacademyway.org` on the Preview and Production Vercel projects.
2. Deploy this branch.
3. **Password reset:** Users & Access → Actions → Reset Password → confirm inbox delivery.
4. **Invitation:** Invite Users (or Add User with Pending Invite) → confirm invite link email.
5. Optional: Admissions communication send → confirm delivery.
6. Health: `GET /api/ready` / env health should not list `RESEND_API_KEY` as missing.
