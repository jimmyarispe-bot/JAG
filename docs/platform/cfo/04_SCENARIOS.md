# 04 — Scenario Analysis

## Kinds

hiring · salary_changes · enrollment_changes · revenue_growth · expense_growth · acquisitions · capital_purchases · debt · grant_loss · scholarship_changes · custom

## Behavior

Scenarios start from metric-registry actuals, apply assumption deltas, and project revenue / expenses / cash / EBITDA. They do not write to the ledger.

## Conversational triggers

The assistant maps natural-language questions (enrollment −12%, payroll +8%, new building, hire teacher) onto these scenario kinds.
