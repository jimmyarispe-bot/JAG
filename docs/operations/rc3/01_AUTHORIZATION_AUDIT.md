# RC-3 — Authorization Audit

## Scope

API routes (`src/app/api/**/route.ts`), Server Actions (sampled high-risk modules), page guards via `route-authorization.ts`, roles: CEO / Founder / School Leader / Teacher / Parent / Student / Employee.

## Controls reviewed

| Control | Location |
|---------|----------|
| Session AuthN | `middleware.ts` |
| Public allowlist | `src/lib/auth/must-reset-password.ts` |
| API permission gate | `guardApiRoute` |
| Page permission gate | `requirePagePermission` / `requireAuthorizedRoute` |
| Action asserts | `assertPermission` / domain `can*` helpers |
| Org / school scope | `requireOrganizationAccess` / `requireSchoolAccess` |

## Static inventory

Generated by `npm run security:authz-inventory` → `perf-rc3-authz-inventory.json`.

## Role expectations (summary)

| Role | Expected access |
|------|-----------------|
| Founder / CEO | Executive + cross-school where catalog grants unrestricted |
| School Leader | School-scoped admin / ops within assignments |
| Teacher | Teacher workspace + assigned classes/students |
| Parent / Student | Portal-scoped self/family data |
| Employee | HR/self-service within employment scope |

Unauthorized cross-org / cross-school access must fail closed (`TENANT_SCOPE` / 403) **and** rely on RLS as defense-in-depth.

## Issues discovered & fixed (this sprint)

| ID | Finding | Fix |
|----|---------|-----|
| RC3-AUTHZ-01 | `configuration/actions.resolveOrg` trusted client `organization_id` | `requireOrganizationAccess` on every resolve |
| RC3-AUTHZ-02 | EDP import/export/backup accepted client `school_id` / org without membership | Org + school scope checks |
| RC3-AUTHZ-03 | `/api/data/import` trusted `body.schoolId` | School + org membership gates |
| RC3-AUTHZ-04 | `/api/scholarship` upserted by `applicationId` without school bind | Lead→school membership check |
