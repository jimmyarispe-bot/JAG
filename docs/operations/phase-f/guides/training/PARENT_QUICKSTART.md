# Quick Start — Parents

| Field | Value |
|-------|-------|

| **Audience** | Parents |
| **Version** | 1.0.0 |

## Procedures
1. Open school link → Login.  
2. Confirm you see Family Portal home.  
3. Find your child / messages / calendar.  
4. Try Accessibility bar if needed.  
5. Read [Parent Guide](../users/PARENT_GUIDE.md).

## Troubleshooting
Land on Apply Portal only → school must enable parent portal access.
