## Procedures
1. Login → Teacher Studio `/dashboard/teacher`.  
2. Open today’s first session.  
3. Open one student profile.  
4. Confirm you can reach scheduling if required.  
5. Bookmark full [Teacher Guide](../users/TEACHER_GUIDE.md).

## Troubleshooting
Missing Teacher Studio → ask IT for `TEACHER_ACCESS` / teacher permissions.
