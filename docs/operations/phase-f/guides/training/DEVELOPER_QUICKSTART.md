## Procedures
1. Read `../../05_DEVELOPER_HANDBOOK.md`.  
2. `npm install` → configure `.env.local` → `npm run dev`.  
3. Run `npm run typecheck` and one validator.  
4. Read `AGENTS.md` + `ENGINEERING_STANDARDS.md`.  
5. Make a small docs-only or test PR to learn CI.

## Troubleshooting
Build fails on validate scripts → expected; fix registries, don’t skip.
