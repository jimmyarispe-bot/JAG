## Procedures
1. Login → confirm `/dashboard`.  
2. With IT: verify your permissions.  
3. Tour: Students, Admissions, one admin page you own.  
4. Bookmark: Operations Manual `docs/operations/phase-f/02_OPERATIONS_MANUAL.md` (IT).  
5. Read role guide under `guides/admin/`.  
6. Practice password reset path on a test account.

## Troubleshooting
Ask IT before changing permissions in production.
