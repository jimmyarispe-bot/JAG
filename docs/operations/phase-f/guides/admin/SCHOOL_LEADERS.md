# Administrator Guide — School Leaders

| Field | Value |
|-------|-------|
| **Purpose** | Lead school operations in AcademyOS |
| **Scope** | Dashboard modules permitted to school leadership |
| **Audience** | School leaders / executive directors |
| **Prerequisites** | Login; school membership; leadership permissions |
| **Version** | 1.0.0 |

## Procedures

### Configuration
- Academic calendars/programs via Configuration Studio if permitted.  
- User/school assignment is IT-owned unless delegated.

### Permissions
- Sidebar shows only modules your permissions allow.  
- Cross-school access requires explicit assignment.

### Daily operations
1. `/dashboard` operating cards (ED mode when configured).  
2. Admissions pipeline `/dashboard/admissions`.  
3. Student success `/dashboard/students`.  
4. Scheduling / staffing as permitted.  
5. Compliance `/dashboard/compliance` when required.

### Best practices
- Use search `/dashboard/search` before deep nav.  
- Confirm school context before bulk edits.  
- Escalate finance/HR sensitive actions to specialized staff.

## Troubleshooting

| Issue | Action |
|-------|--------|
| Missing module | Permission gap — IT |
| Wrong school data | Membership / school assignment |
| Cannot edit | Read-only permission |
