# Student Guide — AcademyOS Portal

| Field | Value |
|-------|-------|
| **Purpose** | Help students use My Day, schedule, goals, messages |
| **Scope** | `/portal/student/*` |
| **Audience** | Students with `portal.student.access` |
| **Prerequisites** | Login; student portal permission |
| **Version** | 1.0.0 |

## Getting started
1. Login with your student account.  
2. Open **My Day** `/portal/student`.  
3. Check **Schedule** and **Goals**.

## Navigation
| Item | Path |
|------|------|
| My Day | `/portal/student` |
| Schedule | `/portal/student/schedule` |
| Goals | `/portal/student/goals` |
| Messages | Portal messages (as enabled) |

## Common tasks
- Review today’s schedule.  
- Check goal progress.  
- Read messages from school (when available).

## Troubleshooting
| Issue | Action |
|-------|--------|
| See parent menu instead | Account type — ask school |
| Empty schedule | Not published yet — ask teacher |
| Cannot login | Password reset via login page / school IT |

## FAQ
