| **Version** | 1.0.0 |

## Getting started
1. Open the school link → **Login**.  
2. You should land in **Family Portal** (`/portal`).  
3. Use the top navigation: Home, Messages, Calendar, Progress, Documents, Finance, etc.  
4. Optional: Accessibility bar — larger text, high contrast, reduce motion.

## Applying to the school
1. Public inquiry: `/apply`.  
2. After account setup: `/apply/portal` for applications.  
3. Complete forms and upload requested documents.

## Troubleshooting
| Issue | Action |
|-------|--------|
| Sent to apply portal instead | Missing parent portal permission — contact school |
| Cannot see child | Linkage not set — contact school office |
| Payment issues | Contact school finance (confirm live payment provider) |

## FAQ
- **App store app?** No — use mobile browser.  
- **Student login?** Students use student portal mode / `/portal/student`.
