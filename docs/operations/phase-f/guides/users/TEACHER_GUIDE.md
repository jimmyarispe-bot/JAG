# Teacher Guide — AcademyOS

| Field | Value |
|-------|-------|
| **Purpose** | Help teachers complete daily instructional work |
| **Scope** | `/dashboard/teacher`, related student/scheduling views |
| **Audience** | Teachers |
| **Prerequisites** | Login; `teacher.*` / `TEACHER_ACCESS` |
| **Version** | 1.0.0 |

## Getting started
1. Go to the school app URL → **Login**.  
2. Open **Teacher Studio** `/dashboard/teacher`.  
3. Use the work queue / sessions list for today’s tasks.

## Navigation
- Sidebar: Teacher Studio, Students, Scheduling (if permitted).  
- Session detail: `/dashboard/teacher/sessions/[id]`.  
- Student: `/dashboard/teacher/students/[id]`.

## Common tasks
| Task | How |
|------|-----|
| Start day | Open Teacher Studio home |
| Open a session | Click session from queue |
| View student | Students module or teacher student link |
| Attendance | Via permitted attendance/scheduling entry points |
| Messages | Use school communication tools if shown |

## Troubleshooting
| Issue | Action |
|-------|--------|
| Teacher menu missing | Ask IT for teacher permissions |
| Cannot see class | School assignment / roster |
| Page error | Retry; report time + URL to support |

## FAQ
- **Mobile app?** Use the website on a phone browser (responsive).  
- **Parent view?** Teachers use dashboard, not `/portal`.
