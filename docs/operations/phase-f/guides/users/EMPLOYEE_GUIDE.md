# Employee Self-Service Guide

| Field | Value |
|-------|-------|
| **Purpose** | Complete leave and onboarding self-service tasks |
| **Scope** | `/dashboard/employee` |
| **Audience** | Employees with linked HR record |
| **Prerequisites** | Login; `employee.self_service`; linked employee |
| **Version** | 1.0.0 |

## Getting started
1. Login.  
2. Open **Employee** `/dashboard/employee`.  
3. Complete only your own requests.

## Common tasks
- Submit leave request.  
- Complete onboarding checklist items assigned to you.  
- Update information only where the form allows.

## Troubleshooting
| Issue | Action |
|-------|--------|
| Page forbidden | Not linked / missing permission — HR |
| See someone else’s data | **Stop** and report to HR/IT immediately |
| Submit error | Retry; capture screenshot for HR |
