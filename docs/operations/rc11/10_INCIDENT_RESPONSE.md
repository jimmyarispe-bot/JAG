# Incident response guide

1. **Detect** — monitoring alert or user report  
2. **Triage** — severity (SEV1 outage → SEV4 cosmetic)  
3. **Contain** — feature flag / disable cron / rollback  
4. **Communicate** — status to Founder/ops channel  
5. **Remediate** — fix forward or restore  
6. **Verify** — smoke + health endpoints  
7. **Postmortem** — within 72h for SEV1/SEV2  

See also `docs/operations/phase-f/runbooks/`.
