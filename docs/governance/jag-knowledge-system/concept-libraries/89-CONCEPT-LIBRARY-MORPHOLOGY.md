## 1. Definition

**Morphology** is **understanding meaningful word parts — prefixes, suffixes, and roots — and how they affect pronunciation, spelling, and meaning**.

**JAG definition ID:** `SL-CL-MOR-DEF-001`

---

## 2. Purpose

Expand vocabulary; support multisyllabic decoding and encoding; build academic language.

---

## 3. Educational Importance

Morphology unlocks word analysis for upper elementary through secondary text; bridges SL to content literacy and LitLab.

---

## 4. Developmental Progression

| Stage | Focus |
|-------|-------|
| **1** | Inflections (-s, -ed, -ing) |
| **2** | Common prefixes (un-, re-, pre-) |
| **3** | Common suffixes (-ful, -less, -tion) |
| **4** | Latin roots (struct, port, dict) |
| **5** | Greek roots (graph, phon, bio) |
| **6** | Combined analysis — prefix + root + suffix |
