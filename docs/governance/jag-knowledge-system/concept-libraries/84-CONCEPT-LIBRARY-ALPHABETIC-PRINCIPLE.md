## 1. Definition

**Alphabetic Principle (AP)** is the **understanding that letters and letter combinations represent speech sounds in systematic, predictable ways** — the conceptual bridge from oral phoneme manipulation to print-based reading and spelling.

AP integrates **alphabet knowledge** (letter identification, naming, letter-sound distinction) with **phonemic awareness** to establish the insight that print is a code for speech.

| Distinction | Alphabetic Principle | Related |
|-------------|---------------------|---------|
| **Level** | Conceptual + emerging application | Sound-symbol = operational mapping |
| **Print** | Required for full demonstration | PM = oral only |
| **Insight** | "Letters stand for sounds" | Decoding = applying the code |

**JAG definition ID:** `SL-CL-AP-DEF-001`

## 4. Developmental Progression

| Stage | Focus | Example |
|-------|-------|---------|
| **1** | Letter identification | Recognize uppercase/lowercase |
| **2** | Letter naming | Name letters — distinct from sounds |
| **3** | Letter-sound distinction | "Name is /ē/, sound is /e/" |
| **4** | Conceptual AP | "Letters represent sounds in words" |
| **5** | Single letter-sound mapping | /m/ → m (selected consonants) |
| **6** | CVC oral-to-print bridge | Blend /c/ /a/ /t/ → cat with letters |
| **7** | Applied AP in decodable words | Read/spelling simple CVC with taught letters |
| **8** | Handoff | Stable AP → Sound-Symbol Correspondence library (Doc 85) |

**Prerequisites:** Doc 62 PM blend/segment ≥ 4/5 on 3-phoneme tasks.

**Progression type:** Linear with recursive letter review (Doc 45).

## Part II — Enhancement Profiles

### A. Cognitive Science Profile (Doc 52)

| Demand Domain | Level | Notes |
|---------------|-------|-------|
| Working memory | High | Hold phoneme + letter association |
| Visual processing | **High** | Letter form discrimination |
| Auditory processing | High | Phoneme-grapheme binding |
| Long-term memory | **High** | Letter names, shapes, sounds |
| Executive function | Moderate | Inhibit letter-name guessing for sound tasks |
| Attention | High | Dual-code (visual + auditory) |

**Primary processes:** Dual coding, phonological processing, visual orthographic processing, associative learning.

**Instructional implications:** Separate letter-name from letter-sound tasks; multisensory tracing; limit new letters per session (3–5); pair with stable PM skills.

### B. Brain Development Profile (Doc 53)

**Systems:** Visual word form area (emerging), left perisylvian network, auditory cortex, hippocampus (association learning), prefrontal cortex (WM/EF).

**Developmental notes:** Letter learning is experience-dependent; letter reversals common ages 4–7 — instructional not diagnostic; orthographic processing networks strengthen with explicit binding practice.

### C. Instructional Decision Model (Doc 54)

**When to teach:** PM stable; letter identification emerging; readiness for print introduction.

**When NOT to teach:** PM blend/segment unstable; intensive decoding before AP concept established.

**Pacing:** 10–15 min daily; 4–5× weekly; 3–5 new letters per week max.

**Advancement:** L3 on CVC oral-to-print bridge → Doc 85 Sound-Symbol Correspondence.

**Rule keys (future):** `sl.aic.ap.readiness`, `sl.aic.ap.advance`, `sl.schedule.ap.daily`

### D. AI Reasoning Profile (Doc 55)

**Mastery indicators:** Letter-sound ID ≥ 4/5 on taught set; CVC read with taught letters ≥ 4/5; conceptual AP demonstration (explain "letters stand for sounds").

**Struggle indicators:** Letter-name substitution for sound; PM regression; random guessing on CVC.

**Rule keys:** `sl.aic.ap.strategy`, `.intervention`, `.parent`, `.schedule`, `.assess`

## 25–28. Development, Misconceptions, Errors, Observables

**Misconceptions:** Letter names equal sounds; uppercase only; random letter order sufficient; AP same as memorizing sight words.

**Error patterns:** Letter-name for sound; b/d confusion (developmental); CVC blend without letter connection; skipping PM prerequisite.

**Proficient signals:** Correct letter-sound on taught set 4/5; reads CVC with taught letters; explains AP in child language.
