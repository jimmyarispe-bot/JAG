## 1. Definition

**Sound-Symbol Correspondence (SSC)** is the **operational mapping of phonemes to graphemes and graphemes to phonemes** — single letters, digraphs, and initial letter combinations — enabling decoding and encoding at the word level.

SSC is where the alphabetic principle becomes **applied skill**: the learner uses known sound-symbol relationships to read and spell.

**JAG definition ID:** `SL-CL-SSC-DEF-001`

---

## 2. Purpose

Establish the operational unit of structured literacy instruction — the grapheme-phoneme correspondences that drive decoding and encoding.

---

## 3. Educational Importance

SSC is the **engine of word-level reading and spelling**. Without stable SSC, decoding becomes sight-word guessing and encoding becomes letter-name spelling.

## 4. Developmental Progression

| Stage | Focus | Content |
|-------|-------|---------|
| **1** | Consonants (continuous first) | m, s, f, n, r, l |
| **2** | Short vowels | a, i, o, u, e (order per scope/sequence) |
| **3** | Stop consonants | p, t, k, b, d, g |
| **4** | CVC decoding | Blend taught correspondences |
| **5** | CVC encoding | Segment to spell with taught set |
| **6** | Digraphs | sh, ch, th, wh, ck |
| **7** | Initial blends | bl, st, tr, etc. |
| **8** | Long vowel patterns preview | CVCe, vowel teams (bridge to decoding library) |
| **9** | Handoff | Stable CVC + digraphs → Doc 86 Decoding |

**Progression type:** Linear cumulative — new patterns added with recursive review (Doc 45).

## Part II — Enhancement Profiles

### A. Cognitive Science Profile (Doc 52)

| Demand | Level |
|--------|-------|
| Working memory | Very High — hold phoneme chain + retrieve grapheme |
| Visual processing | High — grapheme recognition |
| Auditory processing | High |
| Retrieval | **Very High** — automatic grapheme-phoneme retrieval target |
| Executive function | High — inhibit guessing |

**Instructional implications:** Interleave retrieval practice; cumulative review every session; errorless learning for new digraphs; nonsense words to prevent lexical guessing.

### B. Brain Development Profile (Doc 53)

Phonological assembly regions, visual word form area (developing), hippocampal binding for new grapheme-phoneme pairs, cerebellar timing for fluent mapping.

### C. Instructional Decision Model (Doc 54)

**When:** AP conceptual + PM stable + letter ID complete.  
**When NOT:** Decoding multisyllabic before CVC SSC stable.  
**Pacing:** 15–20 min daily literacy block segment; 4–5× weekly; cumulative review 30%.  
**Advancement:** 4/5 CVC decode + encode with taught set → Decoding library.

### D. AI Reasoning Profile (Doc 55)

**Mastery:** Grapheme-phoneme ID ≥ 4/5; CVC decode ≥ 4/5; CVC encode ≥ 4/5; digraph accuracy ≥ 4/5 when taught.  
**Struggle:** Pattern guessing; vowel confusion; digraph as single letter.

## 19–24. Neurodiversity

Dyslexia: extended SSC dosage; systematic cumulative review. ADHD: shorter bursts; high-frequency review. Dysgraphia: encoding may lag decoding — separate evidence tracks.

---

## 26–28. Misconceptions & Errors

**Misconceptions:** Every letter makes one sound always; digraphs are two separate sounds; vowels optional in decoding.

**Errors:** Vowel reduction errors; b/d, p/q confusion; ch/sh confusion; partial blending.
