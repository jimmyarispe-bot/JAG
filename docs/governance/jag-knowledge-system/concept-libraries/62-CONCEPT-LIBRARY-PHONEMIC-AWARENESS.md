## 1. Definition

**Phonemic Awareness (PM)** is the **explicit awareness of and ability to manipulate individual phonemes** — the smallest units of sound in spoken language — including blending, segmenting, deleting, adding, and substituting phonemes, without reliance on print.

Phonemic awareness is **auditory and oral**. It builds on phonological awareness (word, syllable, onset-rime) and directly bridges to the alphabetic principle, decoding, and encoding.

| Distinction | Phonemic Awareness | Related Concept |
|-------------|-------------------|-----------------|
| **Unit size** | Individual phonemes | Phonological awareness = larger units |
| **Modality** | Listening and speaking | Decoding = print |
| **Required for reading?** | **Essential** — strongest predictor alongside PA | Alphabetic principle adds symbols |
| **Print required?** | No — oral manipulation | Sound-symbol = graphemes |

**JAG canonical definition ID:** `SL-CL-PM-DEF-001`

## 4. Developmental Progression

### 4.1 Typical Progression Sequence (Guidance — Not Gates)

| Stage | Skill Focus | Example Task |
|-------|-------------|--------------|
| **1** | Initial phoneme isolation | First sound in "sun" → /s/ |
| **2** | Final phoneme isolation | Last sound in "map" → /p/ |
| **3** | Medial phoneme isolation | Middle sound in "sit" → /i/ |
| **4** | Phoneme blending (2–3 phonemes) | /s/ /a/ /t/ → sat |
| **5** | Phoneme segmentation (2–3 phonemes) | sat → /s/ /a/ /t/ |
| **6** | Phoneme deletion | "Say 'smile' without /s/" → mile |
| **7** | Phoneme substitution | Change /c/ in cat to /h/ → hat |
| **8** | Phoneme addition | Add /s/ to "top" → stop |
| **9** | Phoneme manipulation (complex) | 4-phoneme blend/segment/delete |
| **10** | Phoneme readiness for print | Stable blend/segment → handoff to Alphabetic Principle library |

**Rule:** Stages are **instructional sequence** — not grade-level locks. Placement uses evidence (Doc 40).

### 4.2 Progression Type (Doc 45)

Primary: **Linear** with **recursive** cumulative review; **spiral** reintroduction of prior phoneme positions (initial/final/medial).

### A. Cognitive Science Profile (Doc 52)

#### Primary Cognitive Processes

| Process | Role in Phonemic Awareness |
|---------|---------------------------|
| **Phonological processing** | Analyze and manipulate individual speech sounds |
| **Phonological loop / WM** | Hold 2–5 phonemes during blend/segment tasks |
| **Auditory discrimination** | Distinguish minimal pairs (/p/ vs /b/) |
| **Metalinguistic awareness** | Treat phonemes as manipulable units |

#### Secondary Cognitive Processes

| Process | Role |
|---------|------|
| **Sequential processing** | Order phonemes correctly in blend/segment |
| **Subvocal rehearsal** | Internal speech during manipulation |
| **Inhibition** | Suppress whole-word response; resist guessing |
| **Pattern recognition** | Phoneme position patterns (initial/final/medial) |

#### Demand Summary

| Demand Domain | Level | Notes |
|---------------|-------|-------|
| **Working memory** | **Very High** | 3–5 phoneme units typical load; highest in SL foundation |
| **Long-term memory** | Moderate | Procedural routines for segment/blend; phoneme inventory |
| **Retrieval** | **High** | Rapid phoneme access for manipulation |
| **Attention** | **High** | Sustained auditory focus 10–15 min |
| **Executive function** | **High** | Inhibition of guessing; task switching between manipulation types |
| **Language** | **High** | Receptive instruction; expressive oral response |
| **Visual processing** | **Low** | Optional letter anchors in later stages — not required for core PM |
| **Auditory processing** | **Very High** | Core modality — discrimination and sequencing |
| **Motor** | **Low** | Tap/count optional — not required for evidence |
| **Metacognitive** | Moderate | "I can stretch the sounds" self-check |

#### Instructional Implications

- Limit sessions to 10–15 minutes — WM ceiling lower than PA for many learners  
- One manipulation type per micro-block (blend OR segment — not both new same session)  
- Use continuous phonation for blending; stop-sounds need explicit teaching  
- Errorless learning for fragile WM profiles  
- Nonsense words isolate PM from vocabulary — use in assessment  
- Spaced retrieval of prior stages every 2–3 sessions  
- Avoid concurrent intensive decoding introduction when PM unstable

### B. Brain Development Profile (Doc 53)

#### Brain Systems Involved

| System | Role | Research Basis |
|--------|------|----------------|
| **Left perisylvian language network** | Phoneme processing and storage | Dyslexia research — instructional not diagnostic |
| **Temporal lobe — auditory cortex** | Fine-grained speech sound discrimination | Language neuroscience |
| **Prefrontal cortex** | Working memory, inhibition, attention | EF research |
| **Broca's area (motor speech)** | Subvocal rehearsal during blend/segment | Phonological loop models |
| **Parietal regions (emerging)** | Cross-modal integration when print introduced later | Literacy development literature |

#### Developmental Considerations

- PM sensitivity to **explicit instruction** — not typically acquired incidentally  
- Emergence varies widely ages 4–8+ — **instructional response** preferred over wait-to-fail  
- Stop consonants (/p/, /t/, /k/) harder to segment than continuants (/m/, /s/, /f/)  
- Multilingual phoneme inventories differ — instruction respects L1 phonology with English target  
- Consolidation benefits from sleep and spaced practice  

#### Neuroplasticity Implications

- Intensive explicit PM instruction produces measurable gains in at-risk readers  
- Repeated manipulation strengthens phoneme representation precision  
- Multisensory engagement (OG) — auditory remains primary for PM  
- Individual response rate varies — dosage adjustment not ability ceiling  

#### Typical Developmental Variability

- Some learners consolidate 3-phoneme blend quickly; others need extended recursive review  
- Medial phoneme isolation often hardest — extended Stage 3 support  
- Temporary plateaus common at 4-phoneme complexity  
- EF and attention profiles modify **rate**, not necessarily **ceiling**  

#### Common Developmental Patterns (Instructional — Not Diagnostic)

| Pattern | Instructional Response |
|---------|------------------------|
| Blend collapse (loses phonemes) | Shorter units; slower pace; continuous phonation |
| Segmentation by syllable not phoneme | Return to onset-rime (Doc 51) before advancing |
| Stop-sound segmentation errors | Explicit articulatory awareness; stretch continuants first |
| Guessing whole word | Inhibition training; nonsense word tasks |
| Attention-mediated inconsistency | Shorter sessions; predictable routines |

#### Implications for Intervention

- Increase **dosage** (4–5× weekly) before reducing **expectations**  
- Tier 2–3 when probes flat despite adequate dosage  
- 1:1 for Tier 3 when WM overload persistent  
- Coordinate with speech-language services when articulation affects discrimination  
- Family home practice reinforces consolidation (Doc 42)

### C. Instructional Decision Model (Doc 54)

#### When to Teach

- **Phonological awareness prerequisite met** — syllable/onset-rime stable (Doc 51 L3 or equivalent evidence)  
- Learner has oral language sufficient for task words  
- **No print decoding required** for core PM stages 1–9  
- Screen fail, enrollment, or placement indicates PM gap  
- Can concurrent with **alphabet introduction** — PM does not require letter knowledge for stages 1–9  
- Before alphabetic principle intensive block if PM gap exists  

#### When NOT to Teach

- **Do not** advance to phoneme-grapheme mapping when blend/segment unstable (guessing risk)  
- **Do not** skip isolation stages (initial/final/medial) — position awareness required  
- **Do not** withhold PM from older struggling readers — age is not a blocker  
- **Do not** extend session when EF shutdown observed — pause and reschedule  
- **Avoid** intensive decoding same session as new PM manipulation type if WM overloaded  

#### Readiness Indicators

- Syllable segmentation ≥ 4/5 (Doc 51 probe)  
- Onset-rime blend/segment ≥ 4/5  
- Responds to oral language; attends 2–3 min oral tasks  
- Can repeat 2-syllable words slowly  

#### Warning Signs

- Whole-word responses on segment tasks — PM concept not established  
- Flat probe trend 3+ sessions — Tier review  
- Frustration/shutdown < 5 min — EF overload  
- Persistent stop-sound errors — articulatory/discrimination work needed  
- Prerequisite PA gap — return to Doc 51 stages  

#### Pacing Recommendations

| Parameter | Recommendation |
|-----------|----------------|
| Minutes per session | 10–15 PM-focused |
| Sessions per week | 4–5 when PM is active target |
| Weeks to proficiency (typical range) | 6–16 depending on entry stage |
| Review ratio | 60% new stage : 40% cumulative review |
| Spacing interval | Review prior stages every 2–3 sessions |
| Phoneme count progression | 2 → 3 → 4 phonemes — not skip |

#### Grouping Recommendations

| Parameter | Value |
|-----------|-------|
| Default | Pairs or small group (3–6) |
| Homogeneity | skill_band on PM stage |
| 1:1 trigger | Tier 3, severe WM/EF overload |
| Wilson context | Min 2 when paired with WRS block metadata |

#### Independent Practice Readiness

- **Ready:** L2 developing on stage — structured home sound games with parent  
- **Not ready:** Cannot perform with teacher model — stay in guided oral practice  
- Home practice: 5–10 min blend/segment play — supplementary evidence only  

#### Generalization Readiness

- L3 on stage in structured setting + performance in **2 varied contexts** (classroom + home)  
- Nonsense word performance confirms PM not vocabulary-dependent  

#### Advancement Readiness

- L3 on 3-phoneme blend + segment + stable isolation → handoff to **Alphabetic Principle** concept library  
- Prerequisite graph: Doc 39 `requires` chain satisfied  
- **Do not** advance to print mapping until PM blend/segment ≥ 4/5 on 3-phoneme CVC oral tasks  

**Decision rule refs (future):** `sl.aic.pm.readiness`, `sl.aic.pm.advance`, `sl.schedule.pm.daily_burst`

```mermaid

  PMA[Phonemic Awareness]
  AP[Alphabetic Principle]
  SSC[Sound-Symbol]
  DEC[Decoding]

  PA -->|requires| PMA
  PMA --> AP
```

| Connection | Type | Description |
|------------|------|-------------|

| PM → fluency | **distant support** | Accurate decoding enables fluency |
