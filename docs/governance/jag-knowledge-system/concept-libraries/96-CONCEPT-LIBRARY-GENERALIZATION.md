## Constitutional & Content Boundaries

JAG IP · Mastery requires generalization — not session-only performance (Doc 6).

---

## 1. Definition

**Generalization** is **applying learned literacy skills in new contexts, texts, settings, and tasks** — demonstrating mastery beyond the instructional environment.

**JAG definition ID:** `SL-CL-GEN-DEF-001`

---

## 2. Purpose

Validate that literacy skills are **owned** by the learner — not context-dependent performance.

---

## 3. Educational Importance

Without generalization, mastery claims are invalid; graduation readiness requires cross-context evidence (Doc 7).

---

## 4. Developmental Progression

| Stage | Focus |
|-------|-------|
| **1** | Varied controlled text — same pattern |
| **2** | Novel words within taught patterns |
| **3** | New setting — different teacher/materials |
| **4** | Cross-task — read + write + discuss same content |
| **5** | Maintenance over time — spaced evidence |
| **6** | Handoff | Generalization demonstrated → Transfer (97) |

## Part II — Enhancement Profiles

### A. Cognitive Science Profile (Doc 52)

Transfer of learning **Very High**; Context independence High; Retrieval under variability High; Metacognition High.

**Instructional implications:** Varied exemplars; multiple settings; delayed probes; avoid over-reliance on single text set.

### B. Brain Development Profile (Doc 53)

Neural consolidation supports context-independent retrieval; generalization strengthens with varied practice.

### C. Instructional Decision Model (Doc 54)

**When:** L3 mastery in controlled setting per prior concept library. **Evidence:** Min 2 contexts + retention interval. **Mastery validation:** Doc 6 bundle rules.
