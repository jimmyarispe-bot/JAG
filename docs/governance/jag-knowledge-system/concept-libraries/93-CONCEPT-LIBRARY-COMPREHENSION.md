## 1. Definition

**Reading Comprehension** is **constructing meaning from text — literal, inferential, and evaluative** — the ultimate literacy outcome for academic and life success.

**JAG definition ID:** `SL-CL-RC-DEF-001`

---

## 2. Purpose

Ensure reading serves meaning; integrate word-level skills into purposeful understanding.

---

## 3. Educational Importance

Comprehension is the literacy outcome graduation readiness and content learning depend on (Doc 7).

---

## 4. Developmental Progression

| Stage | Focus |
|-------|-------|
| **1** | Literal comprehension — controlled text |
| **2** | Inferential — who/what/why implied |
| **3** | Text structure awareness |
| **4** | Grade-level text with fluency support |
| **5** | Cross-text synthesis |
| **6** | Evaluative/critical comprehension |
| **7** | Handoff | Proficient → Generalization (96) / Transfer (97) / LitLab |

## Part II — Enhancement Profiles

### A. Cognitive Science Profile (Doc 52)

Semantic integration **Very High**; Inference **Very High**; WM **Very High**; Background knowledge High; Metacognition High (monitoring understanding).

**Instructional implications:** Text at instructional level; explicit strategy instruction; discussion; avoid text beyond decode ability.

### B. Brain Development Profile (Doc 53)

Default mode + language networks for inference; comprehension integrates all literacy subsystems.

### C. Instructional Decision Model (Doc 54)

**When:** Fluency and vocabulary thresholds met on text band. **When NOT:** Comprehension instruction on text learner cannot decode. **Text complexity:** SIE band matching.

### D. AI Reasoning Profile (Doc 55)

**Mastery:** Running record + comprehension questions ≥ 80%; portfolio artifacts. **Rule keys:** `sl.aic.comprehension.strategy`, `.cross.litlab`, `.enrich.opportunity`
