## 1. Definition

**Decoding** is **accurate word reading through application of phonics rules, syllable patterns, and sound-symbol correspondences** — the primary word recognition pathway in structured literacy.

**JAG definition ID:** `SL-CL-DEC-DEF-001`

---

## 2. Purpose

Enable learners to read unfamiliar words accurately using the alphabetic code — not guessing from context or pictures.

---

## 3. Educational Importance

Decoding is the **central skilled reading mechanism** for dyslexic and all learners in SL. Accuracy precedes fluency and comprehension.

---

## 4. Developmental Progression

| Stage | Pattern | Example |
|-------|---------|---------|
| **1** | Closed syllable CVC | cat, sit, hop |
| **2** | Closed syllable with digraphs | ship, chat |
| **3** | Initial/final blends | stop, clap |
| **4** | Closed multisyllabic | picnic, rabbit |
| **5** | VCE (silent-e) | make, ride |
| **6** | Vowel teams | boat, read |
| **7** | R-controlled | car, bird, turn |
| **8** | Advanced patterns | diphthongs, soft c/g |
| **9** | Multisyllabic with morphological units | prefix + base |
| **10** | Handoff | Proficient decode → Fluency (90) / Orthographic Mapping (88) |

**Progression type:** Linear cumulative with spiral review (Doc 45).

**Instructional implications:** Controlled text at instructional level; cumulative review; error correction immediate; nonsense/decodable words before authentic text.

### B. Brain Development Profile (Doc 53)

Left hemisphere reading network (typical); visual word form area strengthening; phonological assembly; experience-dependent orthographic learning.

### C. Instructional Decision Model (Doc 54)

**When:** SSC stable on CVC + taught digraphs. **When NOT:** Multisyllabic before closed syllable stable. **Pacing:** 20–30 min daily SL block; WRS-aligned metadata min group 2. **Advancement:** 95%+ accuracy on pattern probe → next pattern or Fluency library entry.

### D. AI Reasoning Profile (Doc 55)

**Mastery:** Pattern probe ≥ 95% accuracy; running record aligned; error types analyzed. **Struggle:** Guessing; partial cue; vowel errors persistent. **Rule keys:** `sl.aic.decoding.strategy`, `.group.wilson`, `.schedule.dosage`, `.intervention`

## 19–24. Neurodiversity

Dyslexia: intensive systematic decoding — never substitute cueing. ADHD: shorter text sets. Visual stress: font/spacing accommodations — not lower accuracy criteria.

---

## 26–28. Misconceptions & Errors

**Misconceptions:** Good readers guess; pictures help decoding; skip phonics for "smart" children.

**Errors:** CV-CV misdivision; vowel team confusion; r-controlled errors; silent letter omission.
