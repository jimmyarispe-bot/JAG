## 1. Definition

**Encoding** is **spelling words using phoneme-grapheme mapping, phonics rules, and morphological patterns** — the written output pathway that reinforces and extends decoding.

**JAG definition ID:** `SL-CL-ENC-DEF-001`

---

## 2. Purpose

Build accurate spelling from sound analysis; reinforce decoding through reciprocal learning; support written expression.

---

## 3. Educational Importance

Encoding strengthens phonological processing, reveals decoding gaps, and is essential for written expression and academic success.

---

## 4. Developmental Progression

| Stage | Focus |
|-------|-------|
| **1** | Phonetic spelling — CVC with taught letters |
| **2** | Digraph spelling |
| **3** | Blend spelling |
| **4** | Pattern spelling — VCE, vowel teams |
| **5** | Rule-based spelling — doubling, suffix rules |
| **6** | Morphological spelling — affixes, roots |
| **7** | Handoff | Stable encoding → Written Expression (94) |

## Part II — Enhancement Profiles

### A. Cognitive Science Profile (Doc 52)

WM Very High (segment + retrieve grapheme + motor plan); EF High (planning letter sequence); Motor Moderate–High (handwriting or keyboard); Retrieval Very High.

**Instructional implications:** Oral segment before write; say-spell-say; separate handwriting mechanics from encoding evidence when dysgraphia profile.

### B. Brain Development Profile (Doc 53)

Phonological assembly + motor cortex (handwriting); orthographic output lexicon developing; reciprocal decoding-encoding neural overlap.

### C. Instructional Decision Model (Doc 54)

**When:** PM segment stable; SSC on pattern taught. **When NOT:** Extended composition before CVC encoding stable. **Advancement:** 4/5 dictation on pattern → next stage.

### D. AI Reasoning Profile (Doc 55)

**Mastery:** Dictation probe ≥ 4/5; error analysis by type. **Struggle:** Letter-name spelling; missing phonemes; b/d reversals persistent post-instruction. **Rule keys:** `sl.aic.encoding.strategy`, `.evidence.gap`, `.family.activity`

## 19–24. Neurodiversity

**Dysgraphia:** Oral encoding or keyboard; separate motor accommodation from spelling criteria when profile indicates. **Dyslexia:** Same systematic sequence as decoding — increased dosage.

---

## 26–28. Errors

Omission errors; addition errors; vowel errors; homophone confusion (later stages); morphology errors.
