## 1. Learning Goals

### 1.1 Strand Goal

Develop **explicit awareness of and ability to manipulate the sound structure of spoken language** at word, syllable, and onset-rime levels — without reliance on print — so learners are prepared for phonemic awareness and alphabetic instruction.

### 1.2 Competency Goals (Document 98)

By completion of this library pathway, learners demonstrate proficiency (L3) across **24 competencies** in eight groups:

| Group | Goal | Key Competencies |
|-------|------|------------------|
| **Sentence Segmentation** | Hear sentences as separate words | PA-001, PA-002 |
| **Syllable Blending** | Combine syllable parts orally | PA-003 – PA-005 |
| **Syllable Segmentation** | Separate words into syllables | PA-006 – PA-008, PA-022 |
| **Syllable Manipulation** | Add, delete, substitute syllables | PA-009, PA-010, PA-021 |
| **Rhyme & Alliteration** | Recognize, produce, discriminate rhyme; detect alliteration | PA-011 – PA-013, PA-018 |
| **Onset-Rime Blending** | Blend onset + rime orally | PA-014, PA-015 |
| **Onset-Rime Segmentation** | Split and manipulate onset-rime | PA-016, PA-017, PA-023 |
| **Phoneme Readiness** | Bridge to phonemic awareness library | PA-019 – PA-020, PA-024 |

**Capstone:** `AW-SL-PA-024-v1.0.0` — integrated PA mastery validated for Phonemic Awareness library handoff.

### 1.3 Teacher Competency Goals

After using this guide, teachers can:

- Deliver explicit, sequential PA instruction aligned to Document 98 competencies
- Observe, probe, and document evidence per Documents 27 and 40
- Differentiate and accommodate without lowering success criteria
- Communicate progress to families in plain language
- Use AI Coach recommendations within human-gate boundaries (Documents 29, 41, 47)

## 3. Common Misconceptions

*Learner, teacher, and parent misconceptions — with corrections.*

| Misconception | Who | Correction | Instructional Response |
|---------------|-----|------------|------------------------|
| PA means knowing letter names | All | PA is **oral** — no letters required | Separate alphabet instruction; do not conflate evidence |
| Rhyming alone is sufficient | Teacher | Rhyming is one subskill — full sequence required | Broaden to syllable and onset-rime |
| Child cannot do PA — not ready to read | All | Provide **explicit PA instruction** — do not wait | Tier 2 PA boost; age-neutral placement |
| PA is only for young children | Teacher | Older struggling readers need PA if gap exists | Evidence-based placement on PAJ |
| Multilingual children are confused by PA | All | PA in any language strengthens metalinguistic skill | Leverage home language; strength framing |
| Guessing words is PA | Learner/Teacher | Guessing bypasses sound analysis | Return to segmentation; pause premature print emphasis |
| Each syllable is a word | Learner | Words may have multiple syllables | Clap whole word once; contrast mono/bi |
| cat/car rhyme | Learner | Rhyme = shared **ending** sound | Discrimination tasks (PA-013) |
| Onset includes vowel | Teacher/Learner | Onset = consonant(s) before vowel | Explicit model: /c/ + at |
| Lower criteria = accommodation | Teacher | Accommodations change **access**, not criteria | Extended time, quiet space — same 4/5 threshold |

## 4. Observable Behaviors

### 4.1 Proficient Signals by Stage

| Stage | Proficient Behavior | Threshold |
|-------|---------------------|-----------|
| Sentence | Claps/counts words in 5-word sentence | 4/5 |
| Syllable blend | Blends 2–3 syllables immediately | 4/5; ≤ 3–5 sec latency |
| Syllable segment | Segments 2-syllable words accurately | 4/5 |
| Syllable manipulate | Deletes/adds syllable on prompt | 4/5 |
| Rhyme | Identifies and produces rhymes | 4/5 |
| Onset-rime blend | Blends /c/ + at → cat | 4/5 |
| Onset-rime segment | Splits cat → /c/ … at | 4/5 |
| Phoneme readiness | Isolates initial phoneme (sound, not letter name) | 4/5 |

### 4.2 Not-Yet Signals

| Behavior | Indicates | Action |
|----------|-----------|--------|
| Random clapping | Syllable concept not established | Reduce sentence/word length; model |
| No response after 5+ sec | WM overload or attention | Shorten units; break; reschedule |
| Consistent rhyme errors | Discrimination gap | PA-013 micro-intervention |
| Frustration / shutdown < 5 min | EF overload | Tier 1 EF scaffold; shorter session |
| Flat probe 3 sessions | Instruction mismatch or dosage | Tier 2 review — Document 20 |

### 4.3 Generalization Indicators

- Performs target competency in **2 varied contexts** (e.g., small group + home with parent log verified)
- Maintains performance on **2-week retention probe** (PA-024 requirement)

## 8. Differentiation

### 8.1 By Band

| Band | Profile Signal | Strategies |
|------|----------------|------------|
| **Approaching** | Below 2/5 on probe; needs model every trial | Shorter units; errorless learning; 3-word sentences; continuous blend (no pause) |
| **On-level** | 3–4/5; fading support | Standard success criteria; standard session length |
| **Extension** | 4/5 + low latency; seeks challenge | 7-word sentences; 5-syllable words; nonsense-only blocks; teach-back |

### 8.2 By Learning Profile (Document 19)

| Profile Dimension | Differentiation |
|-------------------|-----------------|
| Attention variability | Shorter sessions; movement breaks; predictable routine |
| Working memory | Chunk units; tap-track; reduce inter-stimulus interval |
| Multilingual | PA in home language + English bridge; strength messaging |
| Speech production | Accept valid phoneme production; extended time |
| High EF load | Split capstone across 2 sessions |

### 8.3 Grouping

| Default | Pairs or small group (3–6) |
| Homogeneity | skill_band on PA stage |
| 1:1 trigger | Tier 3; severe EF shutdown |
| Minimum pair | 2 when paired with WRS block metadata |

## 9. Accommodations

*Support access — not lowered criteria.*

| Accommodation | Application |
|---------------|-------------|
| Extended response time | Oral PA tasks |
| Quiet environment | Reduce auditory distraction |
| Visual/kinesthetic anchor | Tap, blocks for syllables |
| Reduced item set per session | Same 4/5 criteria across sessions |
| Preview instruction | Visual schedule of task steps |
| Multilingual support | PA in home language + English bridge |
| Repeat prompt (max 2×) | Sentence/word presentation |
| Session split | Capstone or high-WM tasks across 2 days |

**Not accommodations:** Lowering 4/5 threshold; skipping PA entirely; accepting letter names for phoneme tasks.

## 10. Executive Function Supports

| EF Component | PA Demand | Support |
|--------------|-----------|---------|
| Working memory | High on blend/manipulate | Chunk; tap-track; shorter units |
| Attention | High — sustained auditory | 10–15 min max; break every 10 min |
| Task initiation | Moderate | Preview; model first trial |
| Cognitive flexibility | Moderate on mixed review | Label task type; fade labels |
| Inhibition | Moderate | Wait for full prompt; reduce guessing pressure |

**Session design:** 10–15 min PA burst · 3–5 min recursive review · 2-min break per 10 min for high-EF profiles.

**Playbook EF section:** Align to Document 22 §4.14 — preview, chunk, timer, movement break.

## 12. Common Instructional Mistakes

| Mistake | Why It Fails | Correct Practice |
|---------|--------------|------------------|
| Introducing letters during initial PA | Conflates PA with alphabetic knowledge | Keep PA oral until competency evidence stable |
| Skipping sentence/word level | Downstream syllable guessing | Teach PA-001 – PA-002 first |
| Advancing on age not evidence | Violates mastery philosophy | PAJ placement from probes |
| Single rhyming unit per year | Insufficient PA breadth | Full Document 98 sequence |
| Long sessions (> 20 min) | WM/attention shutdown | 10–15 min PA-focused |
| No cumulative review | Skills don't consolidate | 30% review every session |
| Accepting syllable count as word count | Word boundary error persists | PA-002 verbal count validation |
| Teaching onset as "first two letters" | Orthographic not phonological | Oral onset-rime only |
| Lowering criteria for struggling learners | False mastery signal | Increase dosage before lowering expectations |
| Parent log as sole L3 evidence | Doc 27 weight cap | Educator verification required |
| Concurrent intensive decoding + new PA | WM overload | Separate blocks or days |
| Ignoring multilingual assets | Misses metalinguistic strength | PA in home language encouraged |

## 13. Family Communication Guidance

### 13.1 Principles (Document 42)

| Principle | Application |
|-----------|-------------|
| Plain language | "Word parts and rhymes" not "phonological awareness" |
| Strengths-first | Celebrate clap games, rhyme notice — not deficit |
| Coach not instructor | Parents reinforce — teachers deliver instruction |
| Capacity-aware | 5–10 min home play — not homework overload |

### 13.2 What to Share

| Timing | Message |
|--------|---------|
| PA entry | "We're building ear skills — hearing words and parts in words — before letter-sound work." |
| L2 developing | Assign Document 100 home activity; invite parent log |
| L3 milestone | Celebrate; explain next stage |
| Stall | "We're giving extra practice at school — here's one fun game for home." |
| PA-024 complete | "Foundation sound play complete — moving to smallest sounds in words." |

### 13.3 What Not to Share

- Wilson proprietary content or step labels as parent homework  
- Diagnostic labels from profile data  
- AI mastery suggestions before educator validation  

### 13.4 Conference Talking Points

1. Current competency title and success criteria in plain language  
2. Probe trend (improving / stable / needs support)  
3. One home activity from Document 100  
4. EF or attention supports in place  
5. Expected timeline — guidance only, not guarantee
