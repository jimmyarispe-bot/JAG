# 04 — Education Classifications

Controlled value sets in `EDUCATION_CLASSIFICATION_CATALOG`.

| Scheme id | Purpose |
|-----------|---------|
| `education.class.program_type` | Program types |
| `education.class.attendance_state` | Attendance states |
| `education.class.enrollment_state` | Enrollment states |
| `education.class.assessment_type` | Assessment types |
| `education.class.intervention_type` | Intervention types |
| `education.class.communication_type` | Communication types |
