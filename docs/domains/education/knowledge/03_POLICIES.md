# 03 — Education Policies

Policy **definitions** in `EDUCATION_POLICY_CATALOG`.

These are metadata only — **no evaluation logic**.

| Id | Kind |
|----|------|
| `education.policy.attendance.minimum_rate` | attendance_threshold |
| `education.policy.attendance.chronic_absence` | attendance_threshold |
| `education.policy.enrollment.documents_required` | enrollment_requirement |
| `education.policy.enrollment.capacity` | enrollment_requirement |
| `education.policy.scholarship.eligibility` | scholarship_requirement |
| `education.policy.graduation.credits` | graduation_requirement |

Each policy declares parameters (`valueType`, examples, units) for later interpreters. Contributors are not bound in D3.0.
