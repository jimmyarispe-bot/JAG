# PER Engine

Platform Enhancement Requests are first-class Studio objects.

Each PER tracks:

- description
- originating pack
- affected services
- status
- recommendation
- implementation history
- packs mentioning the same ID

When a PER appears in multiple industry packs, Studio sets `promoteToFoundation` and recommends promotion to Platform Foundation.

Studio PERs for Studio-local gaps live in `docs/studio/06_PLATFORM_ENHANCEMENT_REQUESTS.md`.
