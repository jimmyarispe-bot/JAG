# Release Manager

Product release track:

```
Development → Alpha → Beta → RC-1 → RC-2 → RC-3 → RC-4 → Certified → Released
```

Legacy `"RC"` remains accepted and ranks as RC-1.

Each release stores:

- release notes
- migration history
- upgrade path
- compatibility matrix

AcademyOS is seeded as the first Studio customer on an **RC-2** track.
