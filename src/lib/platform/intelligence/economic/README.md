# Economic Intelligence — Sprint 046

Economic Intelligence continuously understands the macroeconomic environment surrounding every organization and forecasts how conditions influence strategy, pricing, staffing, funding, operations, and long-term sustainability.

This is macroeconomic organizational intelligence — not accounting. Soft light types compose onto Sprint 021–045 results without owning those domains. Every recommendation carries the eight-field `EconomicLens`.

```ts
const { service } = createEconomicIntelligence();
const result = service.build({ requestId: "economic-quarterly" });
```

The result includes health and area scores, trend/forecast/scenario/analysis suites, six dashboards, executive and board reporting, recommendations, reasoning, projection, persistence, knowledge drafts, and the closed learning loop.
