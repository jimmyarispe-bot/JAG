# Impact Intelligence — Sprint 045

Impact Intelligence measures whether JAG OIOS initiatives produce mission, customer, employee, student, community, financial, grant, program, strategic, operational, innovation, and long-term organizational outcomes.

Every recommendation carries the complete eight-field `ImpactLens`. The package composes onto Sprint 021–044 results through soft light types and never owns those domains.

```ts
const { service } = createImpactIntelligence();
const result = service.build({ requestId: "impact-quarterly" });
```

The result includes health and area scores, measurement/outcome/ROI suites, six dashboards, executive and board reporting, recommendations, reasoning, projection, persistence, knowledge drafts, and the closed learning loop.
