**Program:** D4.2 — Student Support Capability Pack  
**Contributor:** `education.cognition.intervention`

Recommend educational support strategies from Student Success, Academic Progress, and Attendance outputs — without re-running those domains.

- Supporting evidence
- Recommendations and action proposals (never executed)
