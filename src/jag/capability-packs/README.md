# Capability Pack Architecture

**Sprint 019** — Universal contract for installable capability units.

A Capability Pack is the architectural equivalent of an app-store app: versioned, licensed, discoverable, dependency-aware, and composable into Runtime Generation.

```text
Capability Pack
  → enabled by Organization
  → selected by Architecture rules
  → contributed into Runtime Generation
  → versioned / upgraded / deprecated
```

First production pack (next phase): **Identity** — not Attendance.

See `docs/jag-os/capability-packs/`.
