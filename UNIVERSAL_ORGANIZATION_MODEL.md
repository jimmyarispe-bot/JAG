## Constitutional statement

Organizations differ only by:

- **Objects**  
- **Vocabulary**  
- **Rules**  
- **Relationships**  

**Not by architecture.**

Never fork JAG for a vertical. Configure the Universal Organization Model and attach domain intelligence packages.

---

## What this model is

One canonical organizational model represents virtually any organization. Differences are governance profiles, workflows, reporting, and intelligence — not separate codebases.

| Capability | Role |
|---|---|
| Universal Organization | Identity, structure, people, ops facets |
| Organizational Constitution™ | Operating rules Mr. JAG must respect |
| Strategy Execution Engine™ | Goals Only · Strategy Assisted · Strategy Driven |
| Organizational Performance™ | Goals, KPIs, milestones, reviews, 1:1s |
| Governance Profiles | Sole prop → tribal government (config only) |
| Digital Twin link | Projection reference (does not replace Twin) |
